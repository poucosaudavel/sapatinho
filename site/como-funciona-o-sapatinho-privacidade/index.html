Como funciona o Sapatinho por dentro

O Sapatinho não tem base de dados de emails nem de resultados. Explicamos, com o código, o caminho de um sorteio do teu navegador até ao email, e o que fica guardado em cada sítio.

Atualizado a 30 de outubro de 2026

O Sapatinho não tem base de dados. Os nomes e os emails passam pelo nosso servidor só durante o pedido que cria o sorteio. O resultado de cada pessoa vai assinado dentro do seu próprio link, e o email vai cifrado nesse link, só para enviarmos o segundo email. Não guardamos emails, nomes nem resultados. Guardamos apenas contagens anónimas por dia e, durante umas horas, códigos irreversíveis que servem para travar abusos.

O caminho de um sorteio

  1. No teu navegador, quem organiza escreve o nome do grupo, o limite, a data e os nomes e emails dos participantes. Nada disto é guardado no site.
  2. O navegador envia tudo, uma vez, ao nosso servidor (um Cloudflare Worker), num pedido POST /api/create cifrado por HTTPS.
  3. O servidor faz o sorteio em memória e cria um link por pessoa.
  4. O servidor pede ao Brevo, o serviço de envio de emails, que mande um convite a cada participante.
  5. O servidor responde ao navegador de quem organiza com os links, e esquece tudo. Não há base de dados onde escrever.
  6. Cada participante abre o seu link, roda a roleta e o navegador pede ao servidor o segundo email (POST /api/confirm), enviando só o próprio link.

Como é feito o sorteio

O sorteio usa o gerador de números aleatórios criptográfico do servidor (crypto.getRandomValues) para baralhar a lista de nomes. Se alguém ficar com o próprio nome, ou com uma pessoa que não pode tirar (um casal, por exemplo), baralha-se outra vez, até 5000 tentativas.

function draw(names, blocked) {
  for (let attempt = 0; attempt < 5000; attempt++) {
    const r = names.slice();
    for (let i = r.length - 1; i > 0; i--) {           // baralhar (Fisher–Yates)
      const j = rnd(i + 1); [r[i], r[j]] = [r[j], r[i]];
    }
    if (names.every((g, i) => g !== r[i] && !(blocked[g] && blocked[g].has(r[i])))) {
      const m = Object.create(null); names.forEach((g, i) => (m[g] = r[i])); return m;
    }
  }
  return null;  // não há sorteio possível com estas exclusões
}

O sorteio fica feito neste momento. A roleta que cada pessoa vê depois é só a forma de mostrar um resultado que já está decidido, por isso rodar outra vez dá sempre o mesmo nome.

O que está dentro de cada link

Em vez de guardarmos os resultados numa base de dados, cada link leva lá dentro o resultado do seu dono. Um link tem a forma sapatinho-natal.pt/r/<dados>.<assinatura>, e os dados são estes:

CampoO que é
gO nome do grupo
l, dO limite da prenda e a data da troca
nO nome de quem abre o link
tO nome que lhe saiu
pOs nomes do grupo, para a roleta
xO email do dono do link, cifrado (ver abaixo)

A seguir aos dados vai uma assinatura HMAC-SHA256, calculada com uma chave secreta que só o servidor tem. Se alguém mudar uma letra ao link, por exemplo para trocar o nome que lhe saiu, a assinatura deixa de bater certo e o servidor recusa o link.

async function sign(dados, env) {
  const sig = await crypto.subtle.sign("HMAC", await hmacKey(env), new TextEncoder().encode(dados));
  return dados + "." + toB64url(new Uint8Array(sig).slice(0, 12));
}

O email, cifrado

Precisamos do email só para uma coisa: enviar o segundo email, com o nome que te saiu, depois de rodares a roleta. Para não o guardarmos em lado nenhum, ele viaja dentro do teu link, cifrado com AES-GCM. Só o nosso servidor tem a chave para o ler, e só o lê no instante em que envia esse email.

async function sealEmail(email, env) {
  const iv = crypto.getRandomValues(new Uint8Array(12));
  const ct = await crypto.subtle.encrypt({ name: "AES-GCM", iv }, await emailKey(env),
                                        new TextEncoder().encode(email));
  return toB64url(juntar(iv, ct));
}

Quando abres o link, a página tira logo o código do endereço (fica só sapatinho-natal.pt/r), para não ficar no histórico nem nas estatísticas de visitas. Guarda-o apenas nesta aba do navegador, para a página funcionar se a recarregares.

Não usamos cookies de publicidade, não vendemos nem partilhamos emails e não enviamos nada além dos dois emails do sorteio. Os detalhes legais estão na política de privacidade.

Os limites, sem rodeios

  • Quem tem o teu link vê o teu resultado. É assim que o link funciona. Não o reencaminhes.
  • Quem organiza tem os links de todos, para poder reenviar convites. Se os abrir, fica a saber os resultados. Por isso pedimos que não o faça.
  • Os nomes no link estão codificados, não cifrados. Quem souber descodificar o teu link consegue ler o grupo e o nome que te saiu. O email, esse, está cifrado.
  • Os emails passam pelo Brevo, que precisa deles para os entregar e guarda o registo de envio durante um mês. O Brevo também troca os links dos emails por links seus, para contar cliques; no plano gratuito isto não se pode desligar.

O código é público

Todo o código do servidor e do site está no GitHub, em github.com/poucosaudavel/sapatinho. O ficheiro do servidor é o worker/worker.js: tem cerca de 300 linhas e não tem nenhuma ligação a uma base de dados.

Perguntas frequentes

O Sapatinho guarda os emails dos participantes?

Não. O servidor recebe os emails só para enviar os convites e esquece-os no fim do pedido. O email de cada pessoa vai cifrado dentro do seu próprio link, para enviarmos o segundo email, e o serviço de envio (Brevo) guarda o registo de envio durante um mês.

O Sapatinho sabe quem saiu a quem?

Não guarda essa informação. O resultado de cada pessoa só existe dentro do link dessa pessoa.

Alguém pode alterar o link para mudar o nome que lhe saiu?

Não. Cada link tem uma assinatura criada com uma chave secreta do servidor. Um link alterado deixa de ser válido.

Quem organiza vê os resultados?

Só se abrir os links dos outros participantes, que recebe para poder reenviar convites. O Sapatinho nunca lhe mostra os resultados diretamente.

Posso pedir para apagar os meus dados?

O Sapatinho não tem dados teus para apagar. O registo de envio no Brevo apaga-se sozinho ao fim de um mês; se quiseres que seja apagado antes, escreve para ajuda@sapatinho-natal.pt.
